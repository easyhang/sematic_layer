语义层构建助手

Semantic Layer Builder — 从数据表中抽象出可被智能体稳定调用的语义层

在问数问答场景中，核心挑战在于数据层与用户实际问题之间存在语义鸿沟：用户提出的是业务语言，而数据层返回的是结构化字段和 SQL 结果集。语义层的角色就是充当翻译层，在用户问题与底层数据之间建立可被稳定调用的映射。

让 LLM 沿着 "用户问题 → 业务概念 → 原子实体 → SQL → 数据事实 → 业务回答" 的路径可靠执行问数问答，而不是凭猜测拼凑 SQL。

核心约束

  • 每个 L0 原子实体必须可落到 SQL
  • 概念层最多 2 层
  • L1 只能依赖 L0 原子实体，L2 不得依赖其他 L2
  • 禁止循环依赖
  • 不静默臆造业务口径，无法确认的内容必须写入 assumptions
