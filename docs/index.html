Semantic Layer Builder

把业务语言翻译成数据查询

语义层在用户问题与底层数据之间建立可被稳定调用的映射——
让 LLM 沿着"问题 → 概念 → 算子 → SQL → 数据 → 回答"的路径可靠执行问数问答，而不是凭猜测拼凑 SQL。
